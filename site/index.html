// install

三分钟装好，不需要终端基础

文件名中的 arm64 / x64 请按你的 CPU 选择。

macOS

dmg — 拖拽安装
# 1. 下载 dmg，双击打开，把 Deepseek 拖入 Applications

# 2. 应用未签名：首次打开请「右键 → 打开」确认，
#    或到 系统设置 → 隐私与安全性 → 仍要打开

# 3.（可选）校验安装包完整性
#    与 Release 附件 SHASUMS256.txt 逐行比对
shasum -a 256 deepseek-harness-desktop-mac-arm64.dmg

Apple Silicon 选 *-mac-arm64.dmg，Intel Mac 选 *-mac-x64.dmg。

Linux

shell — deb / AppImage
# Debian / Ubuntu（推荐，自动处理桌面项与依赖）
sudo apt install ./deepseek-harness-desktop-linux-x64.deb

# 任意发行版：AppImage
chmod +x deepseek-harness-desktop-linux-x64.AppImage
./deepseek-harness-desktop-linux-x64.AppImage

# AppImage 需要 FUSE（缺失时）：Ubuntu 22.04+
sudo apt install libfuse2

ARM 设备（如树莓派 / ARM 服务器）请选 *-linux-arm64.* 产物。

// faq

常见问题

Gatekeeper 提示「无法验证开发者」怎么办？

应用当前未做签名与公证，这是正常现象。两种放行方式任选其一：

  • 在「应用程序」中右键 → 打开 → 再点「打开」（只需一次）；
  • 或先双击，被拦截后到系统设置 → 隐私与安全性，底部点「仍要打开」。
我的数据（配置、会话、插件）存在哪里？

全部位于用户目录下的 ~/.dsh，与 App 安装位置分离：升级、重装甚至卸载应用都不会动它；不再需要时手动删除该目录即可彻底清理。

如何回退 dsh 版本？

两种方式：

  • 应用内自动回退：更新后新版本连续启动失败 2 次时，应用会自动切回随包内嵌的 dsh 版本，无需手动处理；
  • 手动回退：删除侧载运行时目录即可回到内嵌版本 —— 目录位于系统应用数据区（macOS：~/Library/Application Support/Deepseek/runtimes；Linux：~/.config/Deepseek/runtimes），删除后重启应用即生效。
与官方 deepseek-harness 如何保持同步？

仓库每 6 小时自动检查 npm 上 @deepseek-ai/dsh 的新版本，检测到更新会自动提交一个同步 PR，人工验证后才会合并发版——不做任何静默升级。
